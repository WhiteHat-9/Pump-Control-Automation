# Pump Control & Standby Automation (PLC Project)

This project demonstrates Pump Control, Standby Activation, Dual-Fault Detection, and Alarm Logic using Siemens TIA Portal and PLCSIM.

## 🔧 Features Implemented
- Start/Stop Logic
- Pump A & Pump B sequencing
- Standby Pump Auto-Start on fault
- Two Pump Fault Logic (FLT_TwoPumpFault)
- Alarm blinking logic
- Interlocks, memory bits, timers
